# POLITIKA — Map Reference-Only Index

This is a link-only index for **66 documented cartographic references** (including **44 named topographic sheet leads**) prepared on 27 October 2026. [Historical Map Guide](../../../MAPS_1980_1989.md) · [Map catalogue](../../../MAP_CATALOG.csv) · [Rights and provenance](../../../RIGHTS_AND_PROVENANCE.md).

**No third-party maps, PDFs or screenshots are mirrored.** Period maps, pre-period baseline maps, later topographic maps, modern retrospective maps and uninspected collection leads are separately labelled. For M709 topographic sheets the [UT Austin sheet directory](https://maps.lib.utexas.edu/maps/topo/former_yugoslavia/) provides the individually linked source PDFs; this seed deliberately points to the authoritative directory rather than inventing their file URLs.

## Acquisition standards

- Confirm map publication date, depicted date, revision date and edition separately; date precision must never be fabricated.
- Keep political boundaries from *authentic SFRY maps* distinct from post-1991 successor-country map borders and modern place names.
- For the 1985/1989 yearbooks, individual map pages have not been inspected; until then these are bibliographic acquisition leads only.
- For republic/province maps, historical self-management, civil services and federal jurisdictions can inform the Unaligned NPC without treating real communities as fictional enemies.
- Prioritize individually dated Yugoslav-produced maps and period city plans; retain post-period GeoPDFs for physical relief, comparison and map prototyping, not retroactive history.
